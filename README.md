# seedwork-landing

Landing pages for a nine-day positioning test: two value-proposition variants behind a single router, so the same traffic could be split without touching either page.

The point was not the pages. It was that the go, pivot and kill thresholds were written down twelve days before any traffic arrived, so the result could not be argued backwards from what we already wanted. Volume missed every threshold while the quality signals held, and the recommendation was a pivot rather than a kill.

Built with Claude Code, served as static HTML.
